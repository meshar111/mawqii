# مَوقِعي — منصة ذكاء موقعي 📍

تساعد من ينوي فتح مشروع (مطعم، بقالة، مركز أطفال، مغسلة…) على معرفة **ماذا يفتح وأين**، بناءً على تحليل الأنشطة القائمة حول الموقع وكشف الفجوات.

**التغطية:** ٦ دول خليجية · ٣٣ مدينة · ٦٠٠+ حي · بحث حر بأي حي

> تطوير: فهد العساف — [@Alassafme](https://x.com/Alassafme)

---

## ما الذي يقدّمه التقرير؟
- **درجة الفرصة** من ١٠٠ لكل قطاع
- **خريطة الإشباع** — أي نطاق مزدحم وأيه فارغ
- **الأنشطة القائمة** مع أعدادها وتقييماتها وحالتها (مشبع / متوازن / فجوة)
- **الفرص المتاحة** مبرّرة بالبيانات
- **ترشيحات إضافية** تخدم نفس الحي
- **تحذيرات مالية وتنظيمية** (عمولات التوصيل، الهوامش، المساحات النظامية)
- **تقرير قابل للمشاركة** بشعار المنصة ورقم تقرير وتاريخ، وحفظ PDF

## محرّك الدرجة

## التشغيل محلياً
```bash
npm install
cp .env.example .env      # ضع مفتاح Google Places
npm i -g vercel
vercel dev                # يشغّل الواجهة + الـAPI معاً
```

> `npm run dev` يشغّل الواجهة فقط (ببيانات توضيحية). للبيانات الحيّة استخدم `vercel dev`.

## النشر على Vercel
1. ارفع المشروع على GitHub
2. Vercel ← Import Project
3. **Settings ← Environment Variables** ← أضف `GOOGLE_PLACES_KEY`
4. Deploy

## مفتاح Google
من [console.cloud.google.com](https://console.cloud.google.com):
- فعّل **Places API (New)** و **Geocoding API**
- قيّد المفتاح على هاتين الخدمتين فقط
- اضبط سقف ميزانية من Billing ← Budgets & alerts

## البنية
```
├─ api/analyze.js     ← نقطة التحليل (تحمي المفتاح)
├─ lib/places.js      ← Geocoding + Nearby Search
├─ lib/scoring.js     ← محرّك الدرجة
├─ lib/cache.js       ← تخزين ٣٠ يوماً (يخفض التكلفة ٩٠٪)
└─ src/App.jsx        ← الواجهة
```
